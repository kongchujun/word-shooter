# Kenney Blocky Characters 2.0

- Source: https://kenney.nl/assets/blocky-characters
- Character used: `Models/GLB format/character-a.glb`
- Texture used: `Models/GLB format/Textures/texture-a.png`
- License: Creative Commons Zero (CC0 1.0)

The original `License.txt` from the downloaded archive is kept alongside the
model. Attribution is not required, but credit goes to Kenney.

Only one of the 18 characters is included. Every red/blue player clones this
model and gets a small team-coloured vest at runtime, so the browser downloads
about 134 KB of character assets instead of the complete 2.1 MB pack.
